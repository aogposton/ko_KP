# ko_KP

The localization files from North Korea's RedStar 3.0 Operating system.

Use this to understand the differences between ko_KP (NK) and ko_KR (SK).

These files can be useful to anyone who wants to either localize an application
for North Korea or for various OPSEC activities (e.g. better malware attribution)

i18n => /usr/share/i18n/
l10n => /usr/share/locale/
